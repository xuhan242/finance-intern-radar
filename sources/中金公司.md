## 接口

```
POST https://cicc.zhiye.com/api/Jobad/GetJobAdPageList
Content-Type: application/json
Origin:  https://cicc.zhiye.com
Referer: https://cicc.zhiye.com/social/jobs
```

请求体：

```json
{
  "PageIndex": 0,
  "PageSize": 100,
  "LocId": [],
  "Category": ["3"],
  "KeyWords": "",
  "SpecialType": 0,
  "PortalId": "",
  "DisplayFields": ["Category", "Kind", "LocId", "PostDate", "Salary", "Org"]
}
```

认证要求：无。不需要登录、cookie、签名或加密参数。PageSize 100 可分页取全量。

`DisplayFields` 决定扩展字段是否有值：不含 `LocId` 则 `LocNames` 为空，不含 `Org` 则部门为空。

## 字段映射

| 目标字段 | 接口字段 | 说明 |
|---|---|---|
| 岗位名 | `JobAdName` | 形如 `项目实习生-银行组(J19332)`，末尾括号内为职位号 |
| 部门 | `Org` | 需在 DisplayFields 中声明 |
| 业务条线 | `ClassificationOne` | |
| 城市 | `LocNames` | 数组，可为多城市 |
| 发布时间 | `PostDate` | ISO 8601，如 `2026-09-30T18:14:39` |
| 岗位性质 | `Kind` | `实习` / `全职` |
| 分类 | `Category` | `项目实习` / `校园招聘/暑期实习` / `社会招聘` |
| 稳定 ID | `Id` | UUID，深链参数用此值 |
| 备用 ID | `JobAdId` | 数字，如 `151259924` |

不落盘字段：`Duty`（职责全文）、`Require`（要求全文）、`WorkWeChatQrCode`（企业微信二维码）。

**时间基准字段：** `PostDate` —— 用于时间窗口判定与结果排序。

## 深链模板

```
https://cicc.zhiye.com/custom/projectxq?jc=3&hideMenu=1&jobAdId={Id}
```

`jobAdId` 参数取 UUID 形态的 `Id` 字段，非数字 `JobAdId`。已在渲染页面逐一比对确认。

## 合规备注

接口为门户自身调用的公开 JSON 接口，不涉及验证码、登录墙或加密参数，无需绕过任何技术措施。返回体内含企业微信二维码字段与 JD 全文，按数据红线排除，仅取岗位名、部门、城市、发布时间、岗位性质与深链。
