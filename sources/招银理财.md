# 招银理财（暂缓）

采集时间：2026-10-08 ｜ 数据口径：公开搜索与招行招聘门户形态实测

| 项 | 值 |
|---|---|
| 机构类型 | 理财子（行业规模第一） |
| 招聘系统 | 招商银行统一招聘门户 `career.cmbchina.com`（自建 React SPA） |
| **收录结论** | **暂缓** —— 招银理财实习经母行统一渠道发布，母行门户为 SPA 壳，接口未抓包 |

## 实测结果

1. 「2027 届招商银行招银理财暑期实习生招聘公告」经招行统一招聘渠道发布（银行招聘网 2026-07 转载），招银理财无独立招聘官网（`cmbchinawm.com` 为产品官网）；
2. `career.cmbchina.com/campus/home` 为 566B React 壳（main.d37c8446.js，78 个懒加载 chunk 静态 grep 未命中业务接口）；
3. **移动端网关已定位（2026-10-09 凌晨补充）**：`cmb-recruitment-mobile.paas.cmbchina.com`，bundle 内 baseURL=`/api`，业务端点含 `/job/getList`、`/job/getDetail`、`/job/getJobTypeList`、`/job/getRecruitingOrgList` 等——但直连返回 404 SCG9999，真实调用前缀（版本号/服务名）需浏览器抓包确认。

## 复测判据

浏览器抓包 `cmb-recruitment-mobile.paas.cmbchina.com` 的 job/getList 真实请求形态（一次抓包可同时覆盖招行与招银理财两个主体）。
