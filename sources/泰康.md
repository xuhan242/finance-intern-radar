## 接口

```
POST https://jobtaikang.zhiye.com/api/Jobad/GetJobAdPageList
Content-Type: application/json
Origin:  https://jobtaikang.zhiye.com
Referer: https://jobtaikang.zhiye.com/jobs
```

请求体：

```json
{
  "PageIndex": 0,
  "PageSize": 100,
  "LocId": [],
  "Category": ["3"],
  "KeyWords": "",
  "SpecialType": 0,
  "PortalId": "",
  "DisplayFields": ["Category", "Kind", "LocId", "PostDate", "Org"]
}
```

认证要求：无。不需要登录、cookie、签名或加密参数。PageSize 100 可分页取全量。

`PortalId` 传入皮肤名（如 `taikangamc`）不改变返回结果，实测无效。

**采集策略**

默认全部列出并标注 `Org`，不做自动过滤。理由：噪音量被时间窗口压住——177 条为全量存量（最早至 2023 年），但近 30 天仅 8 条、近 7 天 0 条，单次输出为个位数行，全列成本低于过滤误伤成本。

已验证的两类过滤陷阱：

- 按主体白名单过滤，会漏掉第三方投资部、产品中心、人寿总公司资产配置研究——方向对口但不在泰康资产法人下。
- 按标题关键词过滤，会两头出错：甘肃分公司"合规法律与风险管理岗"标题含"风险管理"，实为养老分公司合规岗；"产品中心实习生"标题宽泛，实为资管产品岗。

## 深链模板

```
https://jobtaikang.zhiye.com/custom/zcdetail?hideAll=1&jc=3&jobAdId={Id}
```

`jc` 为 CategoryId（日常实习取 3），`jobAdId` 取 UUID 形态的 `Id` 字段。该模板取自 `/custom/zcshixi` 渲染页面上的真实岗位链接。同租户另存在 `gddetail` 路由（泰康基金官网使用，参数结构一致），二选一待实测确认。

## 实习性质识别

`Kind` 字段可用但不完全可靠：177 条中 17 条将实习岗标为 `全职`。岗位名普遍含"实习生"字样，可作为交叉校验。

## 已知问题

**同一岗位号重复出现。** 实测 J42623、J66255、J59793、J70684 四个职位号各出现 2 次，`Id` 不同、`PostDate` 不同（如 `集团战略宏观研究实习生(J42623)` 分别挂在 2024-04-12 与 2024-02-07）。去重键须用职位号或 `JobAdName`，仅按 `Id` 去重会重复计数。

**长期挂岗较多。** 集团总部主体下最老的在招实习岗发布于 2023 年，说明"在招"不等于"近期新增"，时间窗口过滤为必要环节。
