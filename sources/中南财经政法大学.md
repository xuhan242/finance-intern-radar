## 字段映射

| 输出字段 | 来源 |
|---|---|
| title | `title`（公告标题，常含机构与届别） |
| entity | `companyName`（含北京网聘/前锦网络等代发主体，如实标注） |
| date | `createTime`（"2026/10/16 18:27:29" 斜杠格式，取日期） |
| url | 列表页（岗位详情为 SPA 路由，careerDetail/recruitDetail 等形态均渲染 404，无稳定公开详情 URL——北森标准皮肤先例） |
| post_no | `id` |

本地过滤：`_FIN_TITLE_RE`（title/companyName/positionNames 三处命中任一）。

## 探索留痕（复测备用）

- `type` 参数非干净实习筛（type=2 混杂、type=7 页面筛 API count=0）；`title=实习` 是唯一可靠服务端过滤。
- 宣讲会接口 `preach/list`（5484 条）与 recruit/list 同栈可用，暂不接（宣讲会非岗位流）。
- 实测样本：招行沈阳/佛山暑期、平安证券 2027 暑期、中德证券长期实习、静瑞/启赋私募等。

## 复测判据

`recruit/list?title=实习` 首页出现 `createTime` 在近 60 天内的条目（当前最新 2026-08-07）。
