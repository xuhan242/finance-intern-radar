# 浙商证券（不接）

采集时间：2026-10-09 ｜ 数据口径：浙商证券招聘门户公开页面实测

| 项 | 值 |
|---|---|
| 机构类型 | 证券公司（卖方） |
| 招聘系统 | 北森经典版（`zszq.zhiye.com`）+ 北森 italent 内推站（`neitui.italent.cn/zszq/jobs`） |
| **收录结论** | **不接** —— 两条线均无实习岗位内容 |

## 实测结果

1. `zszq.zhiye.com` 为经典版门户（`/Campus` 路由、`/alljob` 列表），静态解析无实习岗位条目；
2. 内推站 `neitui.italent.cn/zszq/jobs` 可访问（7.2KB），页面无实习岗位、无可用岗位级 API 线索。

浙商证券 2025 年并购国都证券后，校招/实习以项目制公告运作。

## 复测判据

经典版门户或内推站出现实习岗位条目。
