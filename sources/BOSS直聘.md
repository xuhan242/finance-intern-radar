# BOSS直聘（zhipin.com）

> 渠道性质：第三方招聘平台（直聊模式）。实测日期：2026-10-09
> 结论：**不接**（匿名不可读，硬登录墙 + 强风控；不绕过登录墙为项目红线）

## 实测记录

| 项 | 结果 |
|---|---|
| 探测方式 | headless Chromium 匿名访问搜索页 `https://www.zhipin.com/web/geek/job?query=风控实习&city=101010100` |
| 重定向 | 302 至 `https://www.zhipin.com/web/user/?from=passport-zp&fromUrl=...`（登录/注册页） |
| 风控参数 | URL 携带 `_security_check=1_<时间戳>`（安全校验介入标记） |
| 岗位数据 | 零可见（卡片数 0；页面 body 仅登录界面：APP 扫码/验证码/微信登录） |
| 二次探测 | 延长等待 10s 后仍为登录页，无匿名数据渲染 |

## 不接理由

1. **硬登录墙**：未登录状态下搜索页直接重定向登录页，岗位列表、公司名、深链全部不可见。项目红线 3「不绕过任何反爬措施（验证码、登录墙、签名）」直接命中——无可访问的公开数据层。
2. **强风控**：`_security_check` 参数表明设备指纹/行为检测介入；即使持有登录态，headless/自动化访问会持续触发校验，账号封禁风险高。
3. **账号性质**：BOSS 账号与求职行为强绑定（HR 直聊记录、投递历史），封号损失远超渠道收益；且平台用户协议禁止自动化抓取，自动化即违约。
4. **渠道价值错位**：BOSS 的金融实习岗位以中小机构、代招、FA/财富管理为主；头部券商/公募（本项目官网 32 家 + 实习僧活跃机构的主体）极少在 BOSS 发布日常实习。对「985+财贸层次金融 JD」的边际增量有限。

## 与实习僧的对比

| 维度 | 实习僧 | BOSS直聘 |
|---|---|---|
| 匿名可读 | ✓（列表+详情均匿名可读） | ✗（硬登录墙） |
| 反爬强度 | 低（自定义字体混淆、无强制校验） | 高（`_security_check` 设备/行为风控） |
| 接入姿态 | 合规（真实浏览器、匿名、低频） | 不可（绕登录墙或登录态自动化均越界） |
| 金融实习覆盖 | 券商/PE/VC/保险资管/信托密集 | 中小机构/代招为主 |

## 复测判据

若将来出现以下变化可复测：① 匿名访问搜索页不再重定向登录页（如开放部分岗位预览）；② 平台推出官方开放接口/数据合作。当前判据：**搜索页 URL 是否含 `_security_check` 或重定向 `from=passport-zp`**。

## 替代用法（人工层）

BOSS 的独特价值是 HR 直聊（反馈快），适合人工浏览：用户自行登录搜索目标关键词，对感兴趣的岗位直接沟通——无需工具化，工具在此渠道无合规实现空间。
