## 接口

```
POST https://gjzq.zhiye.com/api/Jobad/GetJobAdPageList
Content-Type: application/json
Origin:  https://gjzq.zhiye.com
Referer: https://gjzq.zhiye.com/jobs
```

请求体同北森通用形态（见 sources/中金公司.md），`Category: ["3"]` 取实习生招聘。认证要求：无。

响应顶层键为大写 `Code / Data / Total`，岗位数组即 `Data`（注意 `Total` 字段恒为 0 不可用，计数取数组长度）。此大写键形态为本批新测北森租户的通用形态，与中金记录的 `data` 小写写法不同。

## 深链模板

```
https://gjzq.zhiye.com/jobs
```

**该门户为北森标准皮肤，岗位详情为页内展开，不存在独立岗位 URL**（2026-10-08 浏览器实测：列表页点击岗位卡片仅展开 JD 浮层，URL 不变、不开新标签，顶部导航与右侧热招栏亦不产生岗位级路由）。深链统一指向门户岗位列表页，用户在页内按类别「实习生招聘」筛选或搜索岗位名。


## 合规备注

接口为门户自身调用的公开 JSON 接口，无验证码、登录墙、签名或加密参数。返回体含 JD 全文与企业微信二维码字段，按数据红线排除。

## 未确认项

- `Total` 字段恒为 0，翻页终止条件需按"返回条数 < PageSize"判定。
