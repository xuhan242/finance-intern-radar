# 暨南大学（收录，渲染路径）

采集时间：2026-10-17 ｜ 数据口径：scdc.jnu.edu.cn 渲染实测（就业信息服务平台）

| 项 | 值 |
|---|---|
| 机构类型 | 高校渠道（entity=招聘金融机构） |
| 招聘系统 | 校方自建「就业信息服务平台」（与港中深同款软件：/job/view/id/ 深链、d_category 语义一致） |
| 列表入口 | `/job/search?d_category=102&time=60&page={N}`（实习=102、近2月=60，均为 URL 参数） |
| **收录结论** | **收录** —— 金融过滤后近 2 月 6 条（国寿安保基金渠道实习生×3、私募基金运营等） |

## 通道特性（与其他高校源的关键差异）

- **列表对非浏览器 TLS 指纹返回空壳**（requests 直拿 99KB 无卡片、无验证码/登录墙/签名，属被动客户端区分）→ 采集走 headless 渲染（贸大 zpxxQuery.do 同模式）。首页 SSR 有岗位链接、/job/search 渲染后满页 14 卡。
- 港中深同款 URL 在暨大不能 requests 直抓（该站对 requests 回壳、港中深回全页）——同款软件不同部署的防线差异，复测时两家分开验。
- 卡片结构：`div.job > div.company > a`（单位）+ `div.name > a`（岗位）+ `span`（日期「YYYY-MM-DD发布」）+ `li`（城市/性质/学历）；性质 li=实习与 d_category=102 双保险。
- 翻页：`?page=N` 查询式有效（路径式 `/job/search/d_category/102/.../page/2` 同样存在）。

## 字段映射

| 输出字段 | 来源 |
|---|---|
| title / entity | 卡片岗位链接 / 公司链接 |
| date | 卡片「YYYY-MM-DD发布」 |
| cities | 城市 li（广东省广州市海珠区 原样） |
| url | `/job/view/id/{id}` 岗位级深链 |
| post_no | 深链 id 段 |

本地过滤：`_FIN_TITLE_RE`（金融关键词，岗位或单位名命中），同上财/港中深口径。

## 复测判据

渲染 `/job/search?d_category=102&time=60` 首页出现 14 卡（若 0 卡＝平台改版或防线升级，对照本档案核卡片结构）。
