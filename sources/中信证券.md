## 接口

```
POST https://global-kong.citics.com/api/v1/recruit/getPositionList
Content-Type: application/x-www-form-urlencoded;charset=UTF-8
Origin:  https://careers.citics.com
Referer: https://careers.citics.com/headquarters/interns
```

表单体（2026-10-09 从前端 bundle 破解）：

```
sysNo=CSE001&recruitType=08&deptype=Headquarter&practice=1&batchId=58&pageNo=1&pageSize=50
```

响应：`{errorCode: 0, errorMsg: "成功", count, positionList: [...]}`。无需登录、无签名、无加密参数。

配套接口（同网关同 sysNo）：

| 接口 | 用途 |
|---|---|
| `getDeptList`（`deptype=Headquarter`） | 部门方向字典：投行 2390 / 研究 2395 / 金融数据 2396 / 投资交易 2399 / 市场销售 2400 / **合规风控 2405** / 运营支持 2409 / 财务 2413 / 职能管理 2414 / 信息技术 3442 |
| `getPositionInfo`（`positionNo`） | 岗位详情 |
| `queryPositionsByDept` | 按部门分组取岗位（页面手风琴用） |

**参数语义**：`recruitType` 05=社招、08=实习；`practice=1` 表实习性质；`batchId` 58=日常实习批次、60=暑期批次——批次号可作为"新一波招聘启动"的信号。

## 字段映射

| 目标字段 | 接口字段 |
|---|---|
| 岗位名 | `positionName` |
| 部门 | `deptName` |
| 工作地点 | `workplace`（自由文本，如"北京/上海/深圳等"） |
| 唯一 ID | `positionNo`（如 5337） |
| 批次 | `batchId` |

**不落盘字段**：`positionDesc`、`qualification`（JD 全文）、`deptdescrip`（部门介绍），按数据红线排除。

**时间基准字段：接口无任何发布时间字段**（`getPositionList` 与 `getPositionInfo` 全字段核查）。按冻结设计启用**轻量 ID 存档**：`skill/state/citics_seen.json` 记录每个 `positionNo` 的首见日期，窗口判定与输出均用首见日期；新增岗位首见日期=当天，自然进入窗口。体检模式的"近 60 天新增"对中信意为"近 60 天内首次发现"。

## 深链模板

```
https://careers.citics.com/headquarters/interns
```

岗位详情为页内弹层（"详情"链接为 `javascript:void(0)`），无岗位级 URL，深链指向频道列表页。

## 合规备注

接口为官网自身调用的公开 JSON 接口（无验证码、登录墙、签名或加密参数）。返回体含 JD 全文，按数据红线排除，仅取岗位名、部门、地点与深链。ID 存档仅保存岗位号与首见日期，不含任何 JD 内容。
