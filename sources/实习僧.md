# 实习僧（shixiseng.com）

> 渠道性质：第三方实习聚合平台（非机构官网），经用户确认作为与官网雷达并列的渠道接入。
> 定位：覆盖"985+财贸层次"金融机构实习 JD，机构维度搜索为主、方向词为辅；输出可分享。
> 实测日期：2026-10-09

## 搜索接口（URL 参数化，页面实测确认）

```
https://www.shixiseng.com/interns?type=intern&keyword={词}&publishTime=mon&sortType=zj&city={城市}&page={N}
```

| 参数 | 值 | 语义 |
|---|---|---|
| type | intern | 实习频道（校招为其他值） |
| keyword | URL 编码 | 标题/公司名模糊匹配 |
| publishTime | mon | 近一月刷新（另有 day/week 档，未实测参数值） |
| sortType | zj | 最新排序（按刷新时间倒序，已抽验：首三条刷新时间 2026-10-08~09） |
| city | 全国 | 城市筛选 |
| page | N | 页码（每页 20 条） |

翻页与筛选全部走 URL 参数，无点击依赖；分页器为 Element UI `ul.el-pager > li.number`。

## 时间基准与窗口

- 列表卡片**无发布时间字段**；详情页显示"YYYY-MM-DD HH:MM:SS 刷新"（刷新时间＝平台对外显示的时间，点开详情即见此时间）。
- **行日期 = 详情页刷新时间**：采集后匿名直连详情页逐条提取（约 1s/条，低频 0.3s 间隔），状态缓存于 `skill/state/shixiseng_seen.json`（url → {seen, refresh}），日常增量只补新岗位。窗口过滤按此日期（与列表"近一月刷新"筛选语义一致）。
- 兜底：详情页取不到时间时用首见日期（存档键 `seen`）。

## 已知坑

1. **自定义字体字符污染**：标题/括号内含私有区字符（`\ue000-\uf8ff`，如 `\ue885` 代表"生"等字），系站点 iconfont 渲染所致。处理：剥离 PUA 字符后做规范化匹配与展示；**不解析字体映射文件**（不越"不绕过反爬"红线），拿不到的字符不还原。
2. **缩写词带筛选查询为空**：`固收` + `publishTime=mon` 返回 0 条（无筛选时有 14 条），`固定收益` 正常。方向词一律用全称。
3. 登录弹窗内含滑块验证码 iframe，不影响匿名浏览列表与详情；不触发、不绕过。
4. 详情页匿名可读（含岗位描述与截止日期），投递动作需登录（由用户自行操作）。

## 合规备注

- 真实浏览器引擎渲染，匿名、低频（每关键词 1-2 页，词间间隔 ≥0.8s），不登录、不逆向接口签名、不解析字体映射。
- 输出仅公司名/岗位名/城市/日薪/周天/深链，不复制 JD 全文、无任何联系方式。
- 站点 robots 与用户协议未见禁止性条款；渠道经用户确认自用并可能分享同学。
