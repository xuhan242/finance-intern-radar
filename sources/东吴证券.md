# 东吴证券

采集时间：2026-10-08 ｜ 数据口径：东吴证券招聘门户公开接口实测

## 基本信息

| 项 | 值 |
|---|---|
| 机构 | 东吴证券股份有限公司（含东吴基金等主体混发） |
| 机构类型 | 证券公司（卖方，关联公募主体东吴基金） |
| 板块 | 卖方 |
| 招聘系统 | 北森（Beisen） |
| 门户域名 | `dwzq.zhiye.com` |
| 数据类型 | 实习岗位（**混在 CategoryId=2 校园招聘内，无独立实习分类**） |
| **收录结论** | **收录** —— 实习岗按标题/Kind 在校园招聘分类内识别 |

## 接口

```
POST https://dwzq.zhiye.com/api/Jobad/GetJobAdPageList
```

请求体同北森通用形态（见 sources/中金公司.md）。响应键为大写 `Code / Data / Total`（`Total` 恒为 0）。认证要求：无。

## 分类编码与实习识别

| CategoryId | 名称 | 说明 |
|---:|---|---|
| 1 | 社会招聘 | 近 60 天 2 条，无实习 |
| 2 | 校园招聘 | **实习岗载体**：在招 16 条全部带实习性质，近 60 天 16 条 |

该租户未设独立实习分类。识别规则：CategoryId=2 内 `Kind=实习` 或岗位名含"实习/助理"（抽样：东吴基金 合规法务助理、产品经理助理、基金会计助理，均 2026-09-10 发布，上海）。**误伤风险**：校招正式岗会被卷入，需按 `Kind` 字段优先判定，Kind 缺失时退回标题词。

## 字段映射

同北森通用（`JobAdName / Org / LocNames / PostDate / Kind / Id`）。**时间基准字段：`PostDate`。**

## 更新频率

| 窗口 | 实习性质岗位新增 |
|---|---:|
| 近 30 天 | 16 |
| 近 60 天 | 16 |

16 条集中发布于 2026-09-10 前后（批量波），其中东吴基金 5 条。对口主体（东吴基金、研究所 8 条）占比高。

## 深链模板

```
https://dwzq.zhiye.com/jobs
```

**该门户为北森标准皮肤，岗位详情为页内展开，不存在独立岗位 URL**（2026-10-08 浏览器实测：列表页点击岗位卡片仅展开 JD 浮层，URL 不变、不开新标签，顶部导航与右侧热招栏亦不产生岗位级路由）。深链统一指向门户岗位列表页，用户在页内按类别「实习生招聘」筛选或搜索岗位名。


## 合规备注

接口为门户自身调用的公开 JSON 接口，无验证码、登录墙、签名或加密参数。返回体含 JD 全文，按数据红线排除。
